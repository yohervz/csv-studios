# CSV Studios

The most beautiful way to view and edit CSV files in VS Code.

## Features

- 📊 View CSV and TSV files in a clean, spreadsheet-like table
- ✏️ Edit cells directly in the table view
- ⚡ Fast rendering, even for large files

## Usage

Open any `.csv` or `.tsv` file and it will automatically open in the CSV Studios table view.

## Requirements

No additional requirements.
